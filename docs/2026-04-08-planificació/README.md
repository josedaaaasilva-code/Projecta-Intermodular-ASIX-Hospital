## Resum de la proposta de solució
El projecte implementarà un sistema de gestió hospitalària amb:
- **PostgreSQL 16** com a base de dades principal.
- **Python** com a llenguatge de programació.
- **Exportacions XML i JSON** per a integració amb la Seguretat Social.
- **Dashboard Power BI** connectat directament a PostgreSQL.
- **Desplegament en Ubuntu Server o Docker**.
- **Seguretat** basada en SSL, data masking i rols.
- **Alta disponibilitat** amb rèplica activa-passiva.
- **Metodologia SCRUM** i gestió de tasques amb JIRA.
